# G1 — SASRec over item ids, likes only (Yambda-50M results)

Frozen before the final protocol moved to Yambda-500M; `analysis/collect.py` does not
regenerate this file.

Experiment 1 of [../../../list.md](../../../list.md). A causal transformer reads a user's
likes as one token per item and is trained to name the next one, scored by dot
product against the item table. Negatives come from the batch, corrected by
logQ. Nothing but the item id enters the model.

- **[research_questions.md](research_questions.md)** — the measured answer,
  hypothesis and tables for every rq1–rq11 question
- Shared background: [metrics](../../../../docs/metrics.md) ·
  [protocol](../../../../docs/protocol.md) · [dataset](../../../../docs/dataset.md)

## Running

```bash
source /home/sonofr/python_venvs/.venv/bin/activate
python -m dcn.main -s experiments/g1_sasrec_item_ids_likes/configs/baseline.py
./experiments/g1_sasrec_item_ids_likes/launchers/core/final_sweep.sh
G1_SEED=1 ./experiments/g1_sasrec_item_ids_likes/launchers/core/final_sweep.sh dim_32
G1_DATASET_SIZE=50m ./experiments/g1_sasrec_item_ids_likes/launchers/core/sweep.sh dim_32
python experiments/g1_sasrec_item_ids_likes/analysis/collect.py --write
```

Config is `dcn/config/generation.py::GenerationExperiment`; `configs/baseline.py` only
states what this experiment pins. Final launchers default to the shared 500M
protocol in `experiments/generation_protocol.py`; smaller runs get dataset and
user-sample suffixes so they cannot overwrite final artifacts.

## Results

Full Yambda-50M likes, items with at least five interactions, and the final
seven days held out by timestamp. Training uses all earlier events and only
items with a trainable embedding; evaluation has 3,414 users and a 33,149-item
catalog. Runs use 20 epochs and report the epoch that ranked best. Baseline is
dim 128, 2 layers, 4 heads (2 kv), ffn 256, dropout 0.1, seq 100. One table per
axis, per list.md rq8. Percentages are against the baseline row of the same
table; `±` is the spread over four runs.

The homework calibration is separate because
`week10_transformers/homework/homework_done.ipynb` loads Yambda-500M. The
matched launcher in `configs/homework_500m.py` reaches recall@100 0.1253 versus the
notebook's 0.1267 before any 50M research-question result is interpreted.

`capped_recall@100` remains in each raw `final_metrics.json`; the tables show
the required primary metric, `recall@100`.

## Findings

Every table uses four full-Yambda-50M runs with the final seven days held out.
The corrected baseline is 0.1120 ±0.0018. Pooling within-variant spread gives
σ = 0.00228, or 2.0% of baseline; changes below roughly 4.1% are treated as
unresolved at the conservative 2σ threshold.

### Architecture and optimization

Removing input LayerNorm is the clearest architecture gain at +5.9%. Width 64
is the best quality/cost point: 99.5% of width-128 recall, half the embedding
parameters, and a 2.3s versus 2.6s median epoch. Width 32 loses 6.4%.

WSD and step schedules are tied at about +4.7% over constant. Cosine and linear
match constant on the corrected protocol; exponential loses 23.8%.

### rq5 — which schedule

WSD (0.1173) and step (0.1171) tie for best, about +4.7% over constant. Cosine
and linear match constant, polynomial loses 5.3%, and exponential loses 23.8%
because it decays too aggressively.

### rq6 — does warmup help

**Warmup is schedule-dependent.** It changes constant and cosine by less than
1%, but raises inverse sqrt from 0.0964 to 0.1075 (+11.5%).

### rq7 — position encoding

ALiBi plus reverse learned positions has the highest mean at 0.1148 (+2.9%),
inside noise. Removing every position signal loses 5.9%; learned positions
without ALiBi lose 3.3–4.6%. A distance prior matters, but no direction or
combination produces a resolved gain over the scheduled reference.

### The rest

**Removing input LayerNorm helps.** It reaches 0.1182 (+5.9%), while removing
the final norm loses 13.3%. Depth, head layout, sequence length, local windows,
FFN ratio, residual norm placement, and BOS do not clear the 2σ threshold.

**SwiGLU has no resolved advantage.** Parameter-matched GELU is +1.7%, inside
noise at the shared hyperparameters.

**Dimension controls both tower and item table.** At width 128 the model has
4.2M embedding and 0.31M deep parameters. Width 64 halves the table while
retaining 99.5% of recall; the tables report both parameter groups separately.

### Remaining measured questions

**µTransfer does not work.** Width 32 selects deep LR 2e-3, but every full-width
μP arm collapses to about 0.0345 versus 0.1116 under standard parameterization.

**The best transformer combination is 0.1206 ±0.0010.** It combines embedding
LR 0.02 with reverse position priors. Learned binned timestamp deltas with
dense concatenation reach 0.1177. Per-layer item embeddings add no resolved
gain while tripling embedding parameters.

**Offline logQ is the best negative-sampling arm.** Offline, uniform random,
online, and uncorrected in-batch score 0.1220, 0.1192, 0.1177, and 0.1028.
Omitting proposal correction is clearly harmful.

## Interpretation limits

- Evaluation contains 3,414 users; four-run changes below about 4.1% remain
  unresolved at the conservative 2σ threshold.
- Width changes embedding capacity and transformer width together.
- Architecture comparisons share hyperparameters; a close result does not
  establish each variant's individually tuned optimum.
